# Tutorial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A corner hint box walks a new player through ten steps, each finished by doing it; skippable; saved.

**Architecture:** `Tutorial` (static steps + `advance`) is pure; `GameState.tutorial_step` is saved; `Game` emits
`acted(what)` for every successful action and stores the step through `set_tutorial_step`; `TutorialHint` (scene in
`shop.tscn`) listens to `Game.acted` and to `saw(what)` from the shop's popup openers.

**Tech Stack:** Godot 4.7 GDScript; headless scene build while the editor is closed.

**Spec:** `docs/superpowers/specs/2026-09-30-tutorial-design.md`

## Global Constraints

As in `docs/superpowers/plans/2026-09-29-expeditions.md` (headless builds, uids restored, `--import` then
`git checkout -- art`, scene tests await a frame first, no co-author trailer, never push). Branch `tutorial` (stacked
on `title`). Suite baseline `241 tests, 1 failed` (known only).

## Review Focus

1. An existing save (no `tutorial_step` key) must not start the tutorial. → Task 1 `test_state`.
2. Doing a later step's action early doesn't skip ahead; the current step still needs its own action. → Task 1.
3. The hint never blocks clicks on the farm except its Skip button. → Task 2 (mouse filters asserted).
4. Refused actions don't advance. → Task 1 `acted` only on success.
5. The hint stays readable over popups (z above PanelHost) and fits beside them. → Task 2 test + Task 3 screenshot.

```gdscript
class_name Tutorial
extends RefCounted
## The first-days tutorial (docs/superpowers/specs/2026-09-30-tutorial-design.md): ten steps, each finished by one
## action (Game.acted) or by opening a popup (TutorialHint.saw). The current step is GameState.tutorial_step:
## 0..STEPS.size()-1 active, STEPS.size() finished, SKIPPED skipped. Only the current step's action advances.

const SKIPPED := -1
const DONE_TEXT := "You know the ranch now — have fun!"
const STEPS: Array[Dictionary] = [
	{"text": "Customers post requests on the Orders board. Open it from the shop door or the Orders tag.", "done": &"orders"},
	{"text": "Accept a request: it shows what the customer wants and by when.", "done": &"accept"},
	{"text": "Click a creature in the pen to open its card.", "done": &"card"},
	{"text": "Train raises a stat for 1 heart (action point). Hearts refill every morning.", "done": &"train"},
	{"text": "Feed or Play keeps a creature happy; happy babies grow up well.", "done": &"care"},
	{"text": "The Market sells feed, eggs, upgrades and pens.", "done": &"market"},
	{"text": "Out of hearts? Press End Day. Eggs hatch and babies grow overnight.", "done": &"end_day"},
	{"text": "Send up to three creatures on an expedition to find eggs and gold. Check the challenges first.", "done": &"expedition"},
	{"text": "Retire two grown creatures to the Stable and breed them: the egg inherits their sparks.", "done": &"breed"},
	{"text": "When a creature meets a request, deliver it from the Orders board.", "done": &"deliver"},
]


static func active(step: int) -> bool:
	return step >= 0 and step < STEPS.size()


static func advance(step: int, what: StringName) -> int:
	return step + 1 if active(step) and STEPS[step]["done"] == what else step
```

- [ ] **Step 3: Script** `ui/tutorial_hint.gd`:

```gdscript
class_name TutorialHint
extends PanelContainer
## The tutorial's corner box on the farm (Tutorial): the current step's text and "n/10", finished by doing it —
## Game.acted for actions, saw() from shop.gd for opening a popup. Skip ends it; after the last step it says goodbye
## and Skip becomes Close. Only Skip takes clicks, so the farm under the box stays usable.


func _ready() -> void:
	%Skip.pressed.connect(func() -> void: Game.set_tutorial_step(Tutorial.SKIPPED))
	Game.acted.connect(saw)
	Game.changed.connect(refresh)
	refresh()


## Something the player did or opened (Game.acted keys, or "orders" / "card" / "market" from shop.gd).
func saw(what: StringName) -> void:
	if Game.state == null:
		return
	var step := Game.state.tutorial_step
	var next := Tutorial.advance(step, what)
	if next != step:
		Game.set_tutorial_step(next)
	refresh()


func refresh() -> void:
	var step: int = Game.state.tutorial_step if Game.state else Tutorial.SKIPPED
	var finished := step == Tutorial.STEPS.size() and _was_active
	visible = Tutorial.active(step) or finished
	if Tutorial.active(step):
		_was_active = true
		%Text.text = Tutorial.STEPS[step]["text"]
		%Step.text = "%d/%d" % [step + 1, Tutorial.STEPS.size()]
		%Skip.text = "Skip tutorial"
	elif finished:
		%Text.text = Tutorial.DONE_TEXT
		%Step.text = ""
		%Skip.text = "Close"


var _was_active := false  ## the goodbye shows only to a player who just finished, not to old saves
```

(Move `var _was_active` above `_ready` when writing the file.) `%Skip` on the goodbye sets `SKIPPED`, which hides it.
